实验4 Cookbook：实车定位（RF2O + AMCL）

对应指导书：docs/实验指导书-实验4_定位实验.pdf。 输入：实验3保存的地图；输出：稳定的 map -> odom -> base_footprint 定位链路。

1. 前置条件

  • 地图文件存在：src/ebot_bringup/maps/nav.yaml 与 nav.pgm。
  • 实验2链路通过：底盘与遥控正常。
  • 实验3链路通过：雷达与建图正常。

没有可用地图时，不要直接做实验4。

2. 目标与验收

检查项通过标准
AMCL 粒子收敛初始分散，几次移动后明显收敛到机器人附近。
/amcl_pose 稳定性静止时小幅波动，移动时轨迹连续无突跳。
TF 链map -> odom -> base_footprint 连贯。

3. 终端分工

终端用途
T1底盘驱动
T2雷达驱动
T3地图 + RF2O + AMCL
T4遥控微动与定位验收

4. 详细步骤

Step 0：所有终端加载环境

T1/T2/T3/T4 
export WS=/home/nvidia/group12/RoboticNavigationXJTU26
cd "$WS"
source /opt/ros/noetic/setup.bash
source devel/setup.bash
export ROS_PACKAGE_PATH="$WS/src:${ROS_PACKAGE_PATH:-}"

Step 1：启动底盘

T1 
roslaunch ebot_bringup bringup.launch

Step 2：启动雷达

T2 
roslaunch ebot_bringup my_lidar.launch

Step 3：启动定位链路

T3 
roslaunch ebot_bringup test_amcl.launch \
  map:=nav.yaml \
  amcl_profile:=baseline

Step 4：初始化位姿并微动收敛

T4
  1. 在 RViz 里把 Fixed Frame 设为 map。
  2. 使用 2D Pose Estimate 在机器人真实位置附近打初值。
  3. 小范围前后/转向移动 10~30 秒，让粒子收敛。
rosrun teleop_twist_keyboard teleop_twist_keyboard.py

Step 5：话题与 TF 验收

T4（或新 tab） 
rostopic echo -n 10 /amcl_pose
rostopic hz /amcl_pose
rosrun tf tf_echo map base_footprint

Step 6：结束流程

T4 -> T3 -> T2 -> T1

先停止车体，再按顺序关闭节点。

5. AMCL Profile 对比（建议）

在同一地图、同一区域做三次定位试验：

roslaunch ebot_bringup test_amcl.launch map:=nav.yaml amcl_profile:=baseline
roslaunch ebot_bringup test_amcl.launch map:=nav.yaml amcl_profile:=fast
roslaunch ebot_bringup test_amcl.launch map:=nav.yaml amcl_profile:=robust
Profile倾向观察重点
fast收敛快看是否容易局部漂移
baseline均衡作为默认基线
robust抗噪稳健看抖动是否降低、恢复是否更稳

7. 常见问题

  • 粒子不收敛：先重新 2D Pose Estimate，再做小范围慢速移动。
  • 位姿跳变：检查激光帧名、TF 连通性、地图是否和当前环境一致。
  • /amcl_pose 没数据：确认 test_amcl.launch 日志中 map_server 与 amcl 都已启动。
