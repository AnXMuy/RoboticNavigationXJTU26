2. 全局前置准备（所有实验通用）

2.1 依赖安装（一次性）

sudo apt update
sudo apt install -y \
  ros-noetic-teleop-twist-keyboard \
  ros-noetic-hector-mapping \
  ros-noetic-gmapping \
  ros-noetic-map-server \
  ros-noetic-tf2-sensor-msgs \
  ros-noetic-move-base-msgs

2.2 工作空间环境（每次新终端）

export WS=/home/nvidia/group12/RoboticNavigationXJTU26
cd "$WS"
source /opt/ros/noetic/setup.bash
source devel/setup.bash
export ROS_PACKAGE_PATH="$WS/src:${ROS_PACKAGE_PATH:-}"

2.3 连接与串口检查

先跑连接辅助脚本，再做实验：

bash tools/lan_ssh_guide.sh
bash tools/board_param_check.sh

2.4 编译建议（Jetson/内存紧张）

默认不要用 -j6。推荐低并发避免 OOM。

catkin_make -j1 -l1

3. 阅读顺序建议

  1. 先完整跑通实验2，确认底盘与遥控链路稳定。
  2. 再做实验3，产出 src/ebot_bringup/maps/nav.yaml 与 nav.pgm。
  3. 然后做实验4，用实验3地图进行定位收敛验证。
  4. 最后做实验5，在稳定定位基础上做导航与避障参数对比。
