# 实验 1 产物说明

## 目录结构

- `实验1_ROS通信机制实验报告.tex`：实验 1 LaTeX 报告源文件。
- `实验1_ROS通信机制实验报告.pdf`：最终 PDF 报告，6 页 A4。
- `catkin_ws/`：ROS 通信机制实验代码，包含话题发布订阅、服务通信和 turtlesim 控制示例。
- `results/`：报告中使用的运行结果截图。
- `INSTALL.md`：代码复现实验步骤。
- `人工智能2302_实验1_ROS通信机制.zip`：历史整理包。
- `人工智能2302_蒋梓轩_汪翌秦_孙靖淞_实验1_ROS通信机制_正式提交.zip`：按指导书“实验报告和代码打包、加密压缩”要求整理的正式提交包，密码为 `robotics12`。

## 正式提交包内容

正式提交包只包含：

- `report/实验1_ROS通信机制实验报告.pdf`
- `code/catkin_ws/`

包内未包含 `build/`、`devel/`、`.DS_Store` 或 `__pycache__` 等临时/编译产物。
