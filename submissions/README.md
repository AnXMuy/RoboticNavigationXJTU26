# 机器人导航课程提交材料

本目录按实验编号整理课程报告、截图、源码和最终提交压缩包。编译输出目录 `build/`、`devel/`、系统临时文件等未纳入版本库。

## 目录

- `lab1/`：实验 1 ROS 通信机制报告、截图、提交压缩包与核心 catkin 源码。
- `lab2/`：实验 2 键控机器人运动报告、截图、提交压缩包与 `vehicle_sim` 源码。
- `lab3-4/`：实验 3 地图构建、实验 4 定位实验的整理产物、截图、地图、配置文件与提交压缩包。
- `lab5/`：实验 5 路径规划报告、截图、地图、`move_base` 配置和参考源码。
- `reference_guides/`：实验指导书备份，便于核对报告内容和实验要求。

## 实验 5 补充说明

实验 5 报告重点补充了“新增未知障碍物，局部代价地图更新”的验证过程：在 Gazebo 中加入静态地图中不存在的障碍物后，`/scan` 被 `obstacle_layer` 写入 `local_costmap`，并经 `inflation_layer` 形成膨胀区域；局部规划器据此调整轨迹，完成动态避障和路径跟踪。
