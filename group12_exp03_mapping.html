实验3 Cookbook：实车地图构建（Hector Mapping）

对应指导书：docs/实验指导书-实验3_地图构建.pdf。 输出目标：生成可用于后续定位/导航的 nav.yaml + nav.pgm 地图文件。

1. 目标与产出

项目要求
实时建图RViz 可看到连续更新的 /map。
闭环质量同一路段往返后，墙体/障碍边缘基本重合，无大面积重影。
地图保存src/ebot_bringup/maps/nav.yaml 与 nav.pgm 成功生成。

2. 建图前操作策略

  • 先选择边界清晰、障碍可重复识别的区域（走廊 + 房间入口优先）。
  • 路线建议：先外圈再内圈，最后回到起点附近形成闭环。
  • 速度建议：低速匀速，急转弯前先减速，避免激光畸变和里程抖动。

不要边转边高速前进，容易导致地图扭曲。

3. 终端分工

终端用途
T1底盘驱动
T2雷达驱动
T3Hector 建图
T4键盘遥控 + 监控 + 存图

4. 执行步骤

Step 0：所有终端加载环境

T1/T2/T3/T4 
export WS=/home/nvidia/group12/RoboticNavigationXJTU26
cd "$WS"
source /opt/ros/noetic/setup.bash
source devel/setup.bash
export ROS_PACKAGE_PATH="$WS/src:${ROS_PACKAGE_PATH:-}"

Step 1：启动底盘

T1 
roslaunch ebot_bringup bringup.launch

Step 2：启动雷达

T2 
roslaunch ebot_bringup my_lidar.launch

Step 3：启动 Hector Mapping

T3 
roslaunch ebot_bringup slam_hector.launch resolution_profile:=baseline

后续需要做分辨率对比时，再改为 fine 或 coarse。

Step 4：遥控采图

T4 
rosrun teleop_twist_keyboard teleop_twist_keyboard.py

按规划路线慢速行驶，尽量覆盖所有待导航区域并回到起点附近闭环。

Step 5：在线检查地图与话题

T4（新开一个 tab 也可以） 
rostopic hz /scan
rostopic hz /map
rostopic echo -n 1 /map | head

期望：/scan 和 /map 都持续更新，map 的尺寸与分辨率合理。

Step 6：保存地图

T4 
cd "$WS/src/ebot_bringup/maps"
rosrun map_server map_saver -f nav

保存后检查：

ls -lh "$WS/src/ebot_bringup/maps/nav.yaml" "$WS/src/ebot_bringup/maps/nav.pgm"

Step 7：结束流程

T4 -> T3 -> T2 -> T1

先停车，再按顺序 Ctrl+C 关闭，避免底盘残留速度。

5. 分辨率对比实验（课程进阶）

在同一路线分别执行三次建图：

roslaunch ebot_bringup slam_hector.launch resolution_profile:=baseline
roslaunch ebot_bringup slam_hector.launch resolution_profile:=fine
roslaunch ebot_bringup slam_hector.launch resolution_profile:=coarse
档位特点风险
fine细节更多，边缘更锐利计算负担更高
baseline综合平衡，推荐默认一般无明显风险
coarse计算压力小，构图更快细节损失，窄通道表达弱

6. 验收与报告材料

  1. 建图过程截图（至少 2 张：中途 + 闭环后）。
  2. 地图文件清单截图（nav.yaml/nav.pgm）。
  3. 分辨率对比截图（若做进阶）。
  4. 路线说明：覆盖区域、闭环位置、异常点。

7. 常见问题

  • 地图出现重影：降低车速，减少急转，重复经过特征区做修正。
  • /map 更新慢：先确认雷达频率，再确认 CPU 是否过载。
  • 保存地图失败：确认当前目录可写，且 map_server 正常安装。
