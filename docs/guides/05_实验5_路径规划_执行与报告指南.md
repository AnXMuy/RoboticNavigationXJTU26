## 3. 规划器切换对比

### 3.1 全局规划器

Navfn：

```bash
roslaunch ebot_bringup test_nav.launch map:=nav.yaml global_planner:=navfn/NavfnROS
```

GlobalPlanner：

```bash
roslaunch ebot_bringup test_nav.launch map:=nav.yaml global_planner:=global_planner/GlobalPlanner
```

### 3.2 局部规划器

TrajectoryPlannerROS：

```bash
roslaunch ebot_bringup test_nav.launch map:=nav.yaml local_planner:=base_local_planner/TrajectoryPlannerROS
```

DWAPlannerROS：

```bash
roslaunch ebot_bringup test_nav.launch map:=nav.yaml local_planner:=dwa_local_planner/DWAPlannerROS
```

## 4. 代价地图档位对比

保守档：

```bash
roslaunch ebot_bringup test_nav.launch \
  map:=nav.yaml \
  costmap_profile_file:=$(find ebot_bringup)/config/navigation/costmap_common_real_conservative.yaml
```

激进档：

```bash
roslaunch ebot_bringup test_nav.launch \
  map:=nav.yaml \
  costmap_profile_file:=$(find ebot_bringup)/config/navigation/costmap_common_real_aggressive.yaml
```

建议比较：
- 路径平滑度。
- 障碍绕行距离。
- 到达目标时间。

## 5. 报告取证清单

- 三终端启动截图。
- RViz 中全局路径与局部轨迹截图。
- `/cmd_vel` 或导航日志片段。
- 规划器/代价地图组合的对比表（至少 2 组）。

## 6. 常见问题

- `move_base` 无路径：先检查 `map`、`amcl_pose`、`scan` 是否正常。
- 机器人原地抖动：适当降低局部规划速度上限或切换到更保守代价地图。
- 局部避障失败：检查雷达盲区、TF 安装角度与膨胀半径参数。
