## 2. 全局前置

```bash
cd /Users/zixuan/XJTU/RoboticNavigation
eval "$(conda shell.zsh hook)"
conda activate ros1_noetic
export ROS_PACKAGE_PATH="$PWD/src:${ROS_PACKAGE_PATH:-}"
```

构建（仅实车）：

```bash
./tools/use_real_profile.sh
./tools/show_build_profile.sh
catkin_make
source devel/setup.bash
```

## 3. 统一启动约定

- 底盘 + TF：`roslaunch ebot_bringup bringup.launch`
- 雷达：`roslaunch ebot_bringup my_lidar.launch`
- 建图：`roslaunch ebot_bringup slam_hector.launch ...`
- 定位：`roslaunch ebot_bringup test_amcl.launch ...`
- 导航：`roslaunch ebot_bringup test_nav.launch ...`

推荐顺序：
1. 先启动 `bringup.launch`。
2. 再启动 `my_lidar.launch`。
3. 最后启动建图/定位/导航功能入口。

## 4. 实验报告取证建议

每个实验都至少保留：

- `rostopic list`、`tf` 结构或 RViz 截图。
