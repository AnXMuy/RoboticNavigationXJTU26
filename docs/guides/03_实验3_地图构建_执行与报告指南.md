# 实验3 地图构建：执行与报告指南（实车版）

对应材料：`docs/实验指导书-实验3_地图构建.pdf`

## 0. 目标

- 在实车上完成激光建图。
- 保存可用于 AMCL/导航的静态地图文件。
- 对比不同建图分辨率参数效果。

## 1. 环境准备

```bash
cd /Users/zixuan/XJTU/RoboticNavigation
eval "$(conda shell.zsh hook)"
conda activate ros1_noetic
export ROS_PACKAGE_PATH="$PWD/src:${ROS_PACKAGE_PATH:-}"
./tools/use_real_profile.sh
catkin_make
source devel/setup.bash
```

## 2. 启动链路

终端 A（底盘 + TF）：

```bash
roslaunch ebot_bringup bringup.launch
```

终端 B（雷达）：

```bash
roslaunch ebot_bringup my_lidar.launch
```

终端 C（Hector 建图）：

```bash
roslaunch ebot_bringup slam_hector.launch resolution_profile:=baseline
```

## 3. 保存地图

完成巡航后保存地图：

```bash
cd /Users/zixuan/XJTU/RoboticNavigation/src/ebot_bringup/maps
rosrun map_server map_saver -f nav
```

预期产物：
- `nav.yaml`
- `nav.pgm`

## 4. 分辨率对比（进阶）

细分辨率：

```bash
roslaunch ebot_bringup slam_hector.launch resolution_profile:=fine
```

粗分辨率：

```bash
roslaunch ebot_bringup slam_hector.launch resolution_profile:=coarse
```

比较维度：
- 地图边界清晰度。
- 墙体厚度与噪声点。
- CPU 占用和实时性。

## 5. 报告取证清单

- 三终端启动截图（底盘、雷达、建图）。
- RViz 中 `/map` 可视化截图。
- `nav.yaml/nav.pgm` 文件列表截图。
- `baseline/fine/coarse` 三档对比结论表。

## 6. 常见问题

- `/scan` 无数据：优先检查雷达串口与供电。
- 地图漂移大：降低运动速度，保持激光视野稳定，检查 TF 安装位姿。
- 保存地图失败：确认 `map_server` 安装、工作目录可写。
