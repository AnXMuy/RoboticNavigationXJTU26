## 1. 仿真实验（文档主线：Gmapping）

### 1.1 切换仿真构建档位并编译

```bash
./tools/use_sim_profile.sh
./tools/show_build_profile.sh
catkin_make
source devel/setup.bash
```

### 1.2 启动仿真底盘与世界

终端A：
```bash
roslaunch ebot_bringup bringup.launch mode:=sim sim_gui:=true
```

预期结果：
- Gazebo 启动并出现 `mycar`。
- `rostopic list` 可见 `/odom`、`/cmd_vel`。

### 1.3 启动 Gmapping 建图

终端B：
```bash
roslaunch ebot_bringup slam_gmapping.launch
```

预期结果：
- 新增节点 `/slam_gmapping`。
- 话题 `/map` 开始发布。

### 1.4 键盘遥控建图

终端C：
```bash
rosrun teleop_twist_keyboard teleop_twist_keyboard.py
```

终端D（可选监控）：
```bash
rostopic hz /map
```

RViz 需要显示：
- `RobotModel`
- `TF`
- `LaserScan`（topic 设为 `/scan`）
- `Map`（topic 设为 `/map`）

预期结果：
- 小车运动后地图逐步扩展、闭环后边界更稳定。

### 1.5 保存地图

终端E：
```bash
cd /Users/zixuan/XJTU/RoboticNavigation/src/ebot_bringup/maps
rosrun map_server map_saver -f nav
ls -lh nav.yaml nav.pgm
```

预期结果：
- 生成 `nav.yaml` 和 `nav.pgm`。
- `nav.yaml` 中 `image` 字段指向正确地图文件。

## 3. 实验要求逐项验收

### 3.1 仿真：激光雷达+Gazebo+建图+保存

核验命令：

```bash
rostopic list | rg '^/map$|^/scan$|^/odom$'
rosnode list | rg 'slam_gmapping|hector_mapping'
```

### 3.2 实车：bringup 联合底盘与雷达启动

核验命令：

```bash
roslaunch ebot_bringup bringup.launch mode:=real
roslaunch ebot_bringup my_lidar.launch mode:=real
```

通过标准：
- `bringup.launch` 负责底盘+静态TF；`my_lidar.launch` 负责雷达。

## 4. 进阶要求实现：分辨率对比（已支持）

文档要求“修改 hector 分辨率并对比地图精度”，当前仓库已做成参数化入口。

### 4.1 仿真分辨率对比

高分辨率：
```bash
roslaunch ebot_bringup slam_hector.launch mode:=sim resolution_profile:=fine
```

低分辨率：
```bash
roslaunch ebot_bringup slam_hector.launch mode:=sim resolution_profile:=coarse
```

### 4.2 实车分辨率对比

```bash
roslaunch ebot_bringup slam_hector.launch mode:=real resolution_profile:=fine
roslaunch ebot_bringup slam_hector.launch mode:=real resolution_profile:=coarse
```

对比建议：
- 固定同一路径建图，分别保存 `nav_fine`、`nav_coarse`。
- 比较墙体边缘清晰度、噪点数量、闭环一致性。

## 6. 常见问题

- `/scan` 不存在：
  - 先确认 `rostopic list` 是否有 `/scan`。
  - 若 Gazebo 内部有激光但 ROS 无 `/scan`（常见于非课程标准环境），建议切换 Ubuntu20.04 + ROS Noetic 复现。
- 地图保存失败：确认当前有 `/map` 发布，且 `maps` 目录有写权限。
- RViz 卡顿：可用 `sim_gui:=false` 先无界面跑 Gazebo，再用 RViz 单独观察。
