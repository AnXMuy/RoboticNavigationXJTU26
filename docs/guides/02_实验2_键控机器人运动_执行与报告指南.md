# 实验2 键控机器人运动：执行与报告指南（实车版）

对应材料：`docs/实验指导书-实验2_键控机器人运动.pdf`

## 0. 目标

- 拉起实车底盘通信链路。
- 使用键盘向 `/cmd_vel` 发布速度指令。
- 验证里程计与 TF 链路。

## 1. 环境准备

```bash
cd /Users/zixuan/XJTU/RoboticNavigation
eval "$(conda shell.zsh hook)"
conda activate ros1_noetic
export ROS_PACKAGE_PATH="$PWD/src:${ROS_PACKAGE_PATH:-}"
./tools/use_real_profile.sh
catkin_make
source devel/setup.bash
```

## 2. 启动底盘驱动

终端 A：

```bash
roslaunch ebot_bringup bringup.launch
```

预期结果：
- 出现底盘串口连接日志。
- `rosnode list` 可见底盘相关节点。

## 3. 键盘控制

终端 B：

```bash
rosrun teleop_twist_keyboard teleop_twist_keyboard.py
```

按键控制机器人移动，观察小车响应。

## 4. 话题与 TF 验证

终端 C：

```bash
rostopic list | egrep '/cmd_vel|/wheel_odom_raw|/tf'
rostopic echo -n 5 /wheel_odom_raw
rosrun tf view_frames
```

重点检查：
- `/cmd_vel` 持续发布。
- `/wheel_odom_raw` 时间戳连续。
- TF 中存在 `wheel_odom -> wheel_base_footprint` 与 `base_footprint -> base_link`。

## 5. 报告取证清单

- `bringup.launch` 终端截图。
- 键控终端截图（含速度指令提示）。
- `/wheel_odom_raw` 输出截图。
- TF 树图（`frames.pdf`）或 RViz TF 视图截图。

## 6. 常见问题

- 串口打不开：检查 `bringup.launch` 中 `base_port` 与权限。
- 机器人不动但有 `/cmd_vel`：检查底盘控制器是否已上线、急停状态是否解除。
- TF 缺失：确认 `static_tf.launch` 已被 `bringup.launch` 正常 include。
