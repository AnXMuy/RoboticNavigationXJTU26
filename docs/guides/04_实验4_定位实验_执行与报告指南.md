# 实验4 定位实验：执行与报告指南（实车版）

对应材料：`docs/实验指导书-实验4_定位实验.pdf`

## 0. 目标

- 使用静态地图 + AMCL 完成实车定位。
- 验证 `map -> odom -> base_footprint` 变换链路。
- 对比不同 AMCL 参数档位的收敛与稳定性。

## 1. 前置检查

确认地图文件存在：

```bash
ls -lh src/ebot_bringup/maps/nav.yaml src/ebot_bringup/maps/nav.pgm
```

## 2. 启动定位链路

终端 A（底盘 + TF）：

```bash
roslaunch ebot_bringup bringup.launch
```

终端 B（雷达）：

```bash
roslaunch ebot_bringup my_lidar.launch
```

终端 C（地图 + RF2O + AMCL）：

```bash
roslaunch ebot_bringup test_amcl.launch map:=nav.yaml amcl_profile:=baseline
```

## 3. 验证项

```bash
rostopic list | egrep '/amcl_pose|/particlecloud|/tf'
rostopic echo -n 5 /amcl_pose
```

检查要点：
- `amcl_pose` 是否稳定收敛。
- `particlecloud` 是否由分散到集中。
- TF 是否完整：`map -> odom -> base_footprint`。

## 4. 参数档位对比（进阶）

快速响应档：

```bash
roslaunch ebot_bringup test_amcl.launch map:=nav.yaml amcl_profile:=fast
```

鲁棒档：

```bash
roslaunch ebot_bringup test_amcl.launch map:=nav.yaml amcl_profile:=robust
```

比较维度：
- 收敛时间。
- 定位抖动幅度。
- 动态干扰下恢复能力。

## 5. 报告取证清单

- 三终端启动截图。
- `/amcl_pose` 连续输出截图。
- RViz 粒子云收敛前后对比截图。
- `fast/baseline/robust` 对比表与结论。

## 6. 常见问题

- AMCL 不收敛：检查地图坐标系与雷达 TF；确认 `initialpose` 设置合理。
- 里程计漂移大：确认 `rf2o_laser_odometry` 是否稳定发布。
- 定位跳变：降低速度、调整 `amcl_profile` 到 `robust`，并排查激光时间戳。
