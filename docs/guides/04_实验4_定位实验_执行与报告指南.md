## 3. 实验要求逐项验收

### 3.1 基础实验：全局定位和跟踪

核验命令：

```bash
rostopic hz /amcl_pose
rostopic hz /particlecloud
```

通过标准：
- 机器人移动时定位结果连续。
- 粒子云在正确区域聚集。

### 3.2 更换不同分辨率静态地图并对比

建议准备 `nav_fine.yaml`、`nav_coarse.yaml` 两张图后执行：

```bash
roslaunch ebot_bringup test_amcl.launch mode:=sim map:=nav_fine.yaml amcl_profile:=baseline
roslaunch ebot_bringup test_amcl.launch mode:=sim map:=nav_coarse.yaml amcl_profile:=baseline
```

对比指标：
- 初始收敛速度。
- 弯道/狭窄区域定位抖动。
- 粒子云发散概率。

## 4. 进阶要求实现：AMCL 参数调优与鲁棒性

当前仓库已提供 3 组 AMCL 参数档位，可直接切换。

### 4.1 参数调优对比（fast / baseline / robust）

```bash
roslaunch ebot_bringup test_amcl.launch mode:=sim map:=nav.yaml amcl_profile:=fast
roslaunch ebot_bringup test_amcl.launch mode:=sim map:=nav.yaml amcl_profile:=baseline
roslaunch ebot_bringup test_amcl.launch mode:=sim map:=nav.yaml amcl_profile:=robust
```

你需要记录：
- 收敛时间（启动到粒子云稳定）。
- 重定位成功率（人工扰动后是否恢复）。
- 轨迹平滑性（是否频繁抖动）。

### 4.2 抗干扰/绑架测试

仿真绑架（将机器人瞬移）：

```bash
rosservice call /gazebo/set_model_state '{model_state: {model_name: mycar, pose: {position: {x: 1.2, y: -0.8, z: 0.02}, orientation: {x: 0.0, y: 0.0, z: 0.7, w: 0.7}}, twist: {linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}, reference_frame: world}}'
```

观察项：
- `/particlecloud` 是否短时发散后重新收敛。
- `/amcl_pose` 是否回到真实位置附近。

实车抗干扰：
- 短时遮挡雷达后移除遮挡，观察粒子云恢复。

## 6. 常见问题

- `Map` 不显示：检查 `nav.yaml` 中 `image` 路径是否正确。
- 粒子云不收敛：先用 RViz `2D Pose Estimate` 手动给初始位姿。
- 实车定位跳变大：优先检查激光时间戳、TF 标定、`amcl_profile` 是否过于激进。
