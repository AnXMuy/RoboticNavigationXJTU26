## 1. 小乌龟话题通信验证（仿真）

### 1.1 启动核心与仿真节点

终端A：
```bash
roscore
```

终端B：
```bash
rosrun turtlesim turtlesim_node
```

终端C：
```bash
rosnode list
rostopic list -v
rostopic info /turtle1/cmd_vel
rosmsg info geometry_msgs/Twist
rqt_graph
```

预期结果：
- 能看到 `/turtle1/cmd_vel`、`/turtle1/pose` 等话题。
- `rqt_graph` 中出现 `turtlesim` 节点。

### 1.2 发布速度命令并读取位姿

终端D：
```bash
rostopic pub -r 10 /turtle1/cmd_vel geometry_msgs/Twist "linear:
  x: 1.0
  y: 0.0
  z: 0.0
angular:
  x: 0.0
  y: 0.0
  z: 0.5"
```

终端E：
```bash
rostopic type /turtle1/pose
rosmsg info turtlesim/Pose
rostopic echo /turtle1/pose
```

预期结果：
- 小乌龟做圆周运动。
- `/turtle1/pose` 持续变化。

报告取证建议：
- `rqt_graph` 截图。
- `/turtle1/pose` 连续输出截图。

## 2. C++ 发布/订阅实验（`plumbing_pub_sub`）

### 2.1 建立工作空间与功能包

```bash
mkdir -p ~/catkin_plumbing/src
cd ~/catkin_plumbing
catkin_make
cd src
catkin_create_pkg plumbing_pub_sub roscpp std_msgs
```

### 2.2 编写节点并编译

在 `plumbing_pub_sub/src` 下实现：
- `demo01_pub.cpp`（10Hz 发布文本）
- `demo02_sub.cpp`（订阅并打印）

在 `plumbing_pub_sub/CMakeLists.txt` 中添加：
```cmake
add_executable(demo01_pub_node src/demo01_pub.cpp)
add_executable(demo02_sub_node src/demo02_sub.cpp)
target_link_libraries(demo01_pub_node ${catkin_LIBRARIES})
target_link_libraries(demo02_sub_node ${catkin_LIBRARIES})
```

编译：
```bash
cd ~/catkin_plumbing
catkin_make
source devel/setup.bash
```

### 2.3 运行与launch

分别运行：
```bash
rosrun plumbing_pub_sub demo01_pub_node
rosrun plumbing_pub_sub demo02_sub_node
```

创建 `plumbing_pub_sub/launch/start_pub_sub.launch`：
```xml
<launch>
  <node pkg="plumbing_pub_sub" type="demo01_pub_node" name="pub_node" output="screen"/>
  <node pkg="plumbing_pub_sub" type="demo02_sub_node" name="sub_node" output="screen"/>
</launch>
```

运行：
```bash
roslaunch plumbing_pub_sub start_pub_sub.launch
```

预期结果：
- 订阅端持续打印发布端文本。
- `roslaunch` 一条命令可同时拉起两个节点。

报告取证建议：
- 发布端与订阅端终端截图。
- `start_pub_sub.launch` 代码截图。

## 3. C++ 服务通信实验（`plumbing_server_client`）

### 3.1 建包与自定义srv

```bash
mkdir -p ~/catkin_plumbing2/src
cd ~/catkin_plumbing2
catkin_make
cd src
catkin_create_pkg plumbing_server_client roscpp rospy std_msgs
cd plumbing_server_client
mkdir -p srv
```

`plumbing_server_client/srv/AddInts.srv`：
```srv
int32 num1
int32 num2
---
int32 sum
```

### 3.2 配置 CMakeLists 和 package.xml

在 `CMakeLists.txt` 中确保包含：
- `find_package(catkin REQUIRED COMPONENTS roscpp rospy std_msgs message_generation)`
- `add_service_files(FILES AddInts.srv)`
- `generate_messages(DEPENDENCIES std_msgs)`
- `catkin_package(CATKIN_DEPENDS roscpp rospy std_msgs message_runtime)`

### 3.3 编写服务端和客户端

`src/demo01_server.cpp`：
- 接收 `num1/num2`
- 返回 `sum`

`src/demo02_client.cpp`：
- 命令行输入两个整数
- 调用服务并打印响应

`CMakeLists.txt` 增加：
```cmake
add_executable(demo01_server_node src/demo01_server.cpp)
add_executable(demo02_client_node src/demo02_client.cpp)
add_dependencies(demo01_server_node ${PROJECT_NAME}_gencpp)
add_dependencies(demo02_client_node ${PROJECT_NAME}_gencpp)
target_link_libraries(demo01_server_node ${catkin_LIBRARIES})
target_link_libraries(demo02_client_node ${catkin_LIBRARIES})
```

编译并运行：
```bash
cd ~/catkin_plumbing2
catkin_make
source devel/setup.bash
rosrun plumbing_server_client demo01_server_node
rosrun plumbing_server_client demo02_client_node 3 8
```

预期结果：
- 服务端打印收到请求。
- 客户端输出 `11`。

报告取证建议：
- 服务端日志截图。
- 客户端调用与返回值截图。
