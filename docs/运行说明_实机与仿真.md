# RoboticNavigation 运行说明（实车）

本文档保留原文件名，但内容已切换为**实车单链路**。
当前仓库不再维护仿真运行流，`src/robot_sim` 与 `src/vehicle_sim` 已通过 `CATKIN_IGNORE` 默认禁用。

## 1. 环境与编译

```bash
cd /Users/zixuan/XJTU/RoboticNavigation
eval "$(conda shell.zsh hook)"
conda activate ros1_noetic
export ROS_PACKAGE_PATH="$PWD/src:${ROS_PACKAGE_PATH:-}"
```

执行实车构建档位：

```bash
./tools/use_real_profile.sh
./tools/show_build_profile.sh
catkin_make
source devel/setup.bash
```

## 6. 参数入口

- Hector 分辨率：`resolution_profile:=baseline|fine|coarse`
- AMCL 档位：`amcl_profile:=baseline|fast|robust`
- 全局规划器：
  - `global_planner:=navfn/NavfnROS`
  - `global_planner:=global_planner/GlobalPlanner`
- 局部规划器：
  - `local_planner:=base_local_planner/TrajectoryPlannerROS`
  - `local_planner:=dwa_local_planner/DWAPlannerROS`
- 代价地图覆盖：`costmap_profile_file:=<yaml_path>`

## 7. 常见排障

- 无 `/scan`：检查 `my_lidar.launch` 中串口权限和 `ydlidar_real.yaml` 串口路径。
- 无 `odom -> base_footprint`：检查 `test_amcl.launch` 是否已拉起 `rf2o_laser_odometry`。
- `move_base` 无输出：确认 TF 链 `map -> odom -> base_footprint -> base_link -> laser_link` 连通。
