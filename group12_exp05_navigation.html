实验5 Cookbook：路径规划与避障（实车）

对应指导书：docs/实验指导书-实验5_路径规划.pdf。 目标是在实车上完成 move_base 导航任务，并进行规划器/参数对比实验。

1. 开始前必须满足

  • 实验4已通过，AMCL 可稳定收敛。
  • 地图文件可用：src/ebot_bringup/maps/nav.yaml。
  • 现场可安全导航，已清除临时危险障碍。

定位不稳时不要进入导航实验，先回到实验4调参。

2. 终端分工

终端用途
T1底盘驱动
T2雷达驱动
T3定位 + 导航总入口（test_nav）
T4RViz 设点与人工监控
T5导航状态监控与数据记录

3. 标准执行流程

Step 0：加载环境（所有终端）

T1/T2/T3/T4/T5 
export WS=/home/nvidia/group12/RoboticNavigationXJTU26
cd "$WS"
source /opt/ros/noetic/setup.bash
source devel/setup.bash
export ROS_PACKAGE_PATH="$WS/src:${ROS_PACKAGE_PATH:-}"

Step 1：底盘与雷达

T1 
roslaunch ebot_bringup bringup.launch
T2 
roslaunch ebot_bringup my_lidar.launch

Step 2：启动导航总链路

T3 
roslaunch ebot_bringup test_nav.launch \
  map:=nav.yaml \
  amcl_profile:=baseline \
  global_planner:=navfn/NavfnROS \
  local_planner:=base_local_planner/TrajectoryPlannerROS

Step 3：RViz 设置与定位初始化

T4
  1. Fixed Frame 设为 map。
  2. 显示项至少勾选：Map、TF、LaserScan、Global Path、Local Path。
  3. 先用 2D Pose Estimate 给初始位姿，再用 2D Nav Goal 发目标点。

Step 4：在线状态检查

T5 
rostopic echo /move_base/status
rostopic hz /cmd_vel
rostopic echo -n 5 /move_base/TrajectoryPlannerROS/global_plan

目标状态应从 ACTIVE 进入 SUCCEEDED；如反复恢复行为，说明参数或环境有问题。

Step 5：安全结束

先 T4 停止发目标，再按 T3/T2/T1 关闭

确保车体静止后再退出节点。

4. 规划器对比实验（必须做）

保持同一张地图、同一组目标点，至少跑以下组合：

4.1 全局规划器对比

roslaunch ebot_bringup test_nav.launch map:=nav.yaml \
  global_planner:=navfn/NavfnROS \
  local_planner:=base_local_planner/TrajectoryPlannerROS

roslaunch ebot_bringup test_nav.launch map:=nav.yaml \
  global_planner:=global_planner/GlobalPlanner \
  local_planner:=base_local_planner/TrajectoryPlannerROS

4.2 局部规划器对比

roslaunch ebot_bringup test_nav.launch map:=nav.yaml \
  global_planner:=navfn/NavfnROS \
  local_planner:=base_local_planner/TrajectoryPlannerROS

roslaunch ebot_bringup test_nav.launch map:=nav.yaml \
  global_planner:=navfn/NavfnROS \
  local_planner:=dwa_local_planner/DWAPlannerROS

5. costmap 档位对比实验（建议做）

# 保守模式
roslaunch ebot_bringup test_nav.launch map:=nav.yaml \
  costmap_profile_file:=$(find ebot_bringup)/config/navigation/costmap_common_real_conservative.yaml

# 激进模式
roslaunch ebot_bringup test_nav.launch map:=nav.yaml \
  costmap_profile_file:=$(find ebot_bringup)/config/navigation/costmap_common_real_aggressive.yaml
模式预期现象关注指标
conservative避障距离更大、路径更绕安全性高，但效率可能下降
aggressive路径更贴边、通过性更强效率提升，但风险更高

6. 验收指标（建议量化）

  1. 成功率：5 次目标任务中成功到达次数。
  2. 平均到达时间：每次从发点到成功到达的时间。
  3. 恢复行为次数：是否频繁触发 recovery。
  4. 轨迹平滑度：急停、急转、抖动情况。

8. 常见问题

  • 发了目标点但不动：先看 /move_base/status 是否 ACTIVE，再看 local costmap 是否被障碍层塞满。
  • 路径明显不合理：检查 global/local planner 与 costmap 参数组合是否匹配。
  • 频繁 recovery：减小局部速度上限、增大膨胀参数或改 conservative profile。
